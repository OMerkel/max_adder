Rules

Max Adder is a two-player strategy game played on an 8 x 8 board with number tiles.

Objective

Score more points than your opponent by collecting number tiles.

One player controls horizontal movement and the other controls vertical movement.

The player who receives the opening score does not make the first regular move.

Movement
  1. Choose an unvisited number tile on the row or column controlled by your marker role.
  2. Move the marker to that tile and add its value to your score.
  3. Players alternate turns after the opening placement and score allocation.
Opening placement

The randomly selected starting player places the marker on any tile and removes it.

The opponent decides which player's score receives that first tile value.

End of Game

The game ends when every tile has been scored or the active player's row or column has no remaining tile.

The player with the highest accumulated score wins.

When a game ends, open the menu and choose New Game to start again.
