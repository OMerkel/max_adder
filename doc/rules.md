# Max Adder

You can play **Max Adder** using these rules. This strategic two-player game
can be played with an ordinary 8 x 8 board and number markers.

## 1. Setting up the game

Determine which player controls a marker horizontally and which player controls
the other marker vertically. The players move the marker across the board in
alternating turns.

The 64 number tiles show integers from -2 to +8, representing 11 different
values. The value shown on each tile is determined by subtracting 4 from the
result of rolling two six-sided dice.

Set up the board as follows:

* Distribute the 64 number tiles randomly across the board.
* Randomly determine which player starts.
* On each of their turns, the starting player controls the marker along the
  rows of the board.
* On each of their turns, the opponent controls the marker along the columns
  of the board.
* The starting player places a marker on a field of their choice and removes
  the number tile.
* Their opponent decides whether the score value of the removed number tile is
   credited to their own score or to the starting player's score.
* The player who does not receive this first score value then makes the first
  move according to the following rules.

## 2. Your objective

The player with the highest accumulated score at the end of the game wins.

## 3. Making a move

From this point on, the players take turns moving the marker to an unvisited
field with a number tile, removing the tile, and adding its value to their own
score.

As mentioned above, one player may move the marker only horizontally, while the
other player may move the marker only vertically.

## 4. End of the game

The game ends when all number tiles have been scored or when a player can no
longer move to a number tile that remains because the row or column containing
the marker has already been cleared.

## 5. Good table manners

These courtesies are not game rules. They make a game at the table pleasant and
respectful.

### Before the game

* Set up the board together and make sure that both players see the same
  starting position.
* Greet each other with a handshake or another greeting that is comfortable and
  appropriate for both of you.

### During the game

* Give your opponent time to consider their move.
  Do not rush or distract them, and do not comment on the position unless
  asked.
* Announce the move clearly when necessary, for example: “from c3 to f6”. Give
  your opponent an opportunity to check the count.
* Treat the board and pieces carefully. If the position is accidentally
  disturbed, restore it together before continuing to play.
* Discuss uncertainties calmly and consult the written rules. If you cannot
  reach an agreement, pause the game and agree on how to resolve the question
  instead of arguing at the board.

### After the game

* Acknowledge the result respectfully and say: “Thank you for the lovely game.”
* Offer a rematch, with the other player moving first.
* Accept graciously if the other person does not want a rematch.
  A rematch is an offer, not an obligation.
